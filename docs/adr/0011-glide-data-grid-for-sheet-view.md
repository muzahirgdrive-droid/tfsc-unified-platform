# ADR-0011: Glide Data Grid for Sheet View

- Status: Accepted
- Date: 2026-10-20

## Context
Agents paste a day of rows from Excel; must feel like Excel.

## Decision
Glide Data Grid (MIT, canvas, native multi-cell paste, keyboard navigation).

## Consequences
Canvas grid needs extra a11y work: an accessible list fallback and labelled toggles.
