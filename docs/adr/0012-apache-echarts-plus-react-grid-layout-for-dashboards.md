# ADR-0012: Apache ECharts + react-grid-layout for dashboards

- Status: Accepted
- Date: 2026-10-20

## Context
Power-BI-grade, customizable dashboards.

## Decision
ECharts for charts (themed with §22 tokens), react-grid-layout for drag/resize with layouts validated server-side against an allow-list of widget ids.

## Consequences
See decision.
